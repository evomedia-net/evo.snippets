evo.confetti

Paper falls slowly and flutters, because it is nearly all surface and almost no mass. This models that — drag, tumble, sway — rather than throwing dots on a ballistic arc.

Using it

<script src="confetti.js"></script>
<script>
  confettiBurst();                        // straight up from the middle
  confettiBurst({ origin: 7 });           // from the top-left corner
  confettiBurst({ origin: 3, direction: 315, count: 200 });
</script>
